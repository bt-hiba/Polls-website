# Polls-website

Un site de sondages interactif permettant aux utilisateurs de créer, gérer et participer à des sondages.

## 📊 Fonctionnalités

- Inscription et connexion des utilisateurs (authentification par email et password)
- Création, modification et suppression de sondages
- Classement des sondages par catégories
- Possibilité de voter pour des options de sondage
- Tableau de bord personnel pour gérer les sondages

## 💻 Technologies Utilisées

### Backend
- **Node.js** avec **Express.js**
- **MySQL** géré via **phpMyAdmin**

### Frontend
- **Angular 18**

## 🛠️ Installation

### Prérequis
- **Node.js** (v18+)
- **MySQL** avec **phpMyAdmin**
- **Angular CLI** (installé avec `npm install -g @angular/cli`)

### Backend
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/nom-utilisateur/poll-website.git
   cd poll-website/backend
   ```
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Configurez la base de données MySQL dans `database/config.js`.
4. Lancez le serveur :
   ```bash
   npm start
   ```

### Frontend
1. Accédez au dossier frontend :
   ```bash
   cd ../frontend
   ```
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le serveur Angular :
   ```bash
   ng serve
   ```
4. Rendez-vous sur `http://localhost:4200` pour accéder à l'application.

## 📝 Configuration

- Modifier les informations de connexion à la base de données dans `backend/database/config.js`.
